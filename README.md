# 숫자 숲 · 어린이 스도쿠

[게임 시작하기](https://csw1735-netizen.github.io/number-forest-sudoku/)

아이들을 위한 2×2~6×6 숫자 퍼즐입니다. 난이도별 10개 판, 랜덤 숫자·방향 변형, 타이머와 별명별 기록을 제공합니다.

- 왕초급 2×2, 초급 3×3, 고급 5×5: 가로·세로 숫자 중복 금지
- 중급 4×4: 가로·세로 및 2×2 구역 숫자 중복 금지
- 왕고급 6×6: 가로·세로 및 2×3 구역 숫자 중복 금지
- 모든 판은 정답이 하나인지 검사합니다. 2×2는 가능한 조합이 적어 반복될 수 있습니다.
- 같은 난이도·같은 판끼리 기록을 비교합니다. 힌트 사용은 연습 기록으로 분리합니다.
- 기록은 같은 기기의 같은 브라우저에 저장되며 다른 기기로 공유되지 않습니다.
- 쉬기 버튼을 누르거나 다른 탭으로 이동하면 판이 가려지고 타이머가 멈춥니다.

별도 설치 없이 index.html을 열거나 GitHub Pages로 이용할 수 있습니다.
